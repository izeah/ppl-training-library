## Instruksi untuk asisten
Gunakan dokumen ini sebagai konteks proyek GYM. Bedakan informasi dari pengguna, rekomendasi umum, dan fakta bersumber eksternal. Jangan mengarang beban latihan, repetisi aktual, riwayat cedera, atau video ID. Katalog adalah bank variasi, bukan daftar untuk dilakukan sekaligus. Pertahankan batas sesi sekitar 60 menit dan tujuan body recomposition kecuali pengguna mengubahnya.
