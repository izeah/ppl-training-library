Sesuaikan jika pengguna memberi jadwal/sesi terakhir yang lebih baru.

## Parameter umum
- Maksimal sekitar 60 menit termasuk pemanasan.
- Umumnya 5–6 gerakan per sesi.
- Compound lebih dulu, isolasi setelahnya.
- Compound: umumnya 3 set × 6–10 atau 8–12 reps; istirahat 90–180 detik.
- Isolasi: umumnya 2–3 set × 10–20 reps; istirahat 60–90 detik.
- Unilateral: reps dicatat per sisi/kaki.
- Awali mayoritas working sets dengan sekitar 2–3 RIR.
- Gunakan double progression: tambah reps dalam rentang; bila seluruh set mencapai batas atas dengan teknik baik dan RIR sesuai, naikkan beban sedikit.
- Jangan menetapkan kilogram tanpa log kemampuan aktual.
- Pemanasan: 3–5 menit kardio ringan, mobilitas dinamis, lalu 1–3 ramp-up sets untuk gerakan compound pertama.
- Hentikan/modifikasi gerakan bila muncul nyeri tajam atau gejala tidak biasa. Gunakan safety pins/spotter untuk squat dan bench berat.

## Template A/B
### Push A — chest emphasis
Bench Press 3×6–8; Incline DB Press 3×8–12; Pec Deck 2×12–15; DB Lateral Raise 3×12–20; Rope Pushdown 3×10–15; Overhead Cable Extension 2×10–15.

### Push B — shoulder emphasis
Machine Shoulder Press 3×8–12; Machine Chest Press 3×8–12; Cable Fly 2×12–15; Cable Lateral Raise 3×12–15/sisi; EZ Skull Crusher 2×10–12; Rope Pushdown 2×12–15.

### Pull A — lat width
Lat Pulldown 3×8–12; Chest-Supported Row 3×8–12; Straight-Arm Pulldown 2×12–15; Face Pull 2×12–20; EZ Curl 3×8–12; Hammer Curl 2×10–15.

### Pull B — back thickness
Assisted Pull-Up 3×6–10; Seated Cable Row 3×8–12; Single-Arm DB Row 2×8–12/sisi; Reverse Pec Deck 2×12–20; Incline DB Curl 3×10–15; Cable Curl 2×10–15.

### Legs A — quadriceps
Back Squat 3×6–10; Leg Press 3×8–12; Seated Leg Curl 2×10–15; Leg Extension 2×10–15; Standing Calf Raise 3×10–15.

### Legs B — hamstrings/glutes
RDL 3×8–10; Hip Thrust 3×8–12; Bulgarian Split Squat 2×8–12/kaki; Lying Leg Curl 2×10–15; Seated Calf Raise 3×12–20.

Template dapat diubah berdasarkan toleransi, progres, dan pemulihan.
