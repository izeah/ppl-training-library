# Profil Pengguna dan Tujuan

## Fakta dari pengguna
- Laki-laki, 28 tahun, tinggi 165 cm, berat 75 kg (angka saat percakapan; perlu diperbarui).
- Pernah latihan gym, tetapi baru memulai kembali.
- Gym memiliki peralatan lengkap.
- Tidak ada cedera/keterbatasan yang dilaporkan saat itu; ini bukan jaminan tidak ada kondisi medis.
- Tujuan: body recomposition, menambah massa otot dan mengurangi lemak.
- Preferensi: latihan 6 hari/minggu, Senin–Sabtu; Minggu istirahat.
- Batas durasi: maksimal 60 menit per sesi.
- Split: Push/Pull/Legs.
- Referensi awal pengguna: artikel PPL SteelFit.

## Preferensi aplikasi
Pengguna ingin membuka aplikasi web, memilih Push/Pull/Legs, lalu melihat katalog gerakan. Setiap detail perlu mencakup target otot utama/pendukung, set, reps, rest per set, alat, setup dan cara melakukan gerakan, tips keselamatan, alternatif alat, gambar referensi, serta tutorial YouTube. Pengguna meminta variasi yang luas sebagai inspirasi, namun program terpilih harus praktis dan tidak berlebihan.

## Estimasi nutrisi yang pernah dibahas
- BMR estimasi sekitar 1.646 kcal/hari.
- Maintenance estimasi sekitar 2.200–2.450 kcal/hari.
- Contoh target awal sekitar 2.150 kcal/hari.
- Protein sekitar 150 g/hari; karbohidrat 245 g; lemak 63 g.
Angka ini perkiraan, bukan pengukuran. Evaluasi melalui tren berat 2–4 minggu, lingkar pinggang, performa, rasa lapar, dan pemulihan.
